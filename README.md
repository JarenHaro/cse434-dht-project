# cse434-dht-project

Socket Project for CSE 434. Distributed Hash Table with Hot Potato Query Processing.

The project involves the design and implementation of two programs:

1. The first program implements an "always-on" manager to support the management of the peers implementing the DHT. 

2. The second program implements the peer protocol that supports the construction and management of the DHT, as well as the ability to query the DHT.

11,500 - 11,999 is the port range for our group (group 21).
